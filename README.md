# 《洄瀾風語：花蓮奇境探索之旅》

一個以**花蓮特有風景、在地美食、風土名產**為故事線索的第一人稱沉浸式文字冒險探索遊戲網站。

## 🌟 遊戲核心特色與設計規範

1. **出發前的雙主軸身分選擇**：
   - 🔰 **初次到訪（初見驚艷 · 探索新奇）**：
     - 以花蓮經典地標（太魯閣峽谷、燕子口、白楊步道水簾洞、清水斷崖、七星潭月牙灣、東大門夜市、瑞穗牧場）與必嚐經典名產（炸蛋蔥油餅、公正包子、花蓮薯、手工麻糬、甘蔗剝皮辣椒、七星柴魚、瑞穗鮮奶）為探索核心。
   - 🧭 **曾經到訪（舊地重遊 · 秘境拾遺）**：
     - 避開觀光喧鬧，尋訪深層歷史人文與風土秘境（松園別館百年松濤、吉安慶修院八十八尊石佛、壽豐白鮑溪翻尋豐田玉、鳳林國際慢城客家菸樓與大菁藍染、林田山檜木老聚落、豐濱石梯坪單面山海蝕壺穴、新社部落噶瑪蘭香蕉絲手工藝、部落麥飯石柴火石頭火鍋、舞鶴小綠葉蟬蜜香紅茶、玉里安通百年弱鹼溫泉與橋頭臭豆腐）。

2. **嚴格情境字數規範**：
   - **每一幕情境描述嚴格控制在 200 ～ 300 字**，文字優美細膩，具備豐富的五感（視覺、聽覺、嗅覺、味覺、觸覺）描摹。
   - 介面右上角即時顯示精準字數統計與「✓ 200-300字」合格標章。

3. **三選一互動機制**：
   - 每幕情境文末**固定提供 3 個具體選擇**，代表不同的探索方向（山線、海線、市街時光、人物對話），決定後續的故事發展。

4. **沉浸式風土系統**：
   - 🎒 **洄瀾行囊**：記錄沿途拾獲的花蓮名產與特產紀念（附詳細背景故事與圖鑑）。
   - 🗺️ **足跡地圖**：點亮花蓮 10 大鄉鎮（秀林、新城、花蓮市、吉安、壽豐、鳳林、光復、豐濱、瑞穗、玉里）解鎖狀態。
   - 🔊 **Web Audio 程序化山海音效**：內建海浪白噪音動態濾波與風鈴音效，完全不需額外下載音訊檔案。
   - 💾 **自動存檔與回溯**：支援 LocalStorage 進度儲存與上一步（悔棋/回溯）功能。

## 🚀 快速啟動

### 方法一：直接點擊批次檔
雙擊執行專案目錄下的 `啟動花蓮探索遊戲.bat`，將自動啟動本地伺服器並開啟瀏覽器。

### 方法二：透過命令列
```bash
cd "d:\20260831 Phaser\hualien-journey"
node server.js
```
伺服器啟動後，請在瀏覽器造訪：`http://localhost:3088`

### 方法三：直接以瀏覽器開啟
直接雙擊 `index.html`，即可在任何現代瀏覽器（Chrome、Edge、Safari、Firefox）離線暢玩。
